# Security

## Reporting a vulnerability

Please email [security@radovar.com](mailto:security@radovar.com) with a description of the issue and the steps to reproduce it. Please do not open a public issue for security problems.

## What this repository covers

This repository publishes the Codevalanche installers and update feed. Reports about the installers, the update feed, update signature checks or the Codevalanche app itself are all welcome at the address above.

Every update is signed with the publisher's Ed25519 key, and the app checks that signature before it installs anything.
